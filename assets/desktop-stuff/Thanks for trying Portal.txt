Hey, thanks for trying Portal!

Seriously, it means a lot. Portal started as a "wait, could a tablet run a
real Linux desktop?" kind of idea, and now here you are, sitting in one.
Hope you have fun with it.

A few things to get you going:

  - This is a real Debian 13 with KDE Plasma 6. Install stuff with
    `sudo apt install <whatever>` in Konsole (no password needed).
  - Want a fancier look? Open CloudDarkRice and run
    "Apply Cloud Dark rice". It downloads about 25 MB the first time
    and you can undo it any time (the README in there says how).
  - Logging out closes Portal. Just open it again to come back.
  - Turn on Portal under Android Settings > Accessibility so shortcuts
    like Alt+Tab work and Android doesn't close the desktop in the
    background.

If something breaks, or you just want to say hi, come find us on GitHub
(the "Portal on GitHub" link right next to this note). Bug reports,
screenshots of your setup, ideas, all welcome.

Thanks again, and enjoy your new desktop :)
