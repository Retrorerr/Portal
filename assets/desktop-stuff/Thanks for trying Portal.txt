Thanks for trying Portal!

Portal is a fork of Local Desktop (github.com/localdesktop), which did the
hard groundwork of running Linux on Android without root. Portal builds on
it with Debian 13, KDE Plasma 6 and GPU acceleration.

A few things to get you going:

  - This is a real Debian 13 with KDE Plasma 6. Install stuff with
    `sudo apt install <whatever>` in Konsole (no password needed).
  - Want a different look? Open CloudDarkRice and run
    "Apply Cloud Dark rice". It downloads about 25 MB the first time
    and you can undo it any time (the README in there says how).
  - Logging out closes Portal. Just open it again to come back.
  - Turn on Portal under Android Settings > Accessibility so shortcuts
    like Alt+Tab work and Android doesn't close the desktop in the
    background.

Bug reports and ideas are welcome on GitHub (the "Portal on GitHub" link
next to this note).
